Tarnów + 50 km · katalog źródeł · __DATE__

Skąd brać wydarzenia z Tarnowa i okolic

Wszystkie znalezione źródła wydarzeń: instytucje miejskie, kultura, lokale, bilety, media, sport, parafie i 30 gmin w promieniu 50 km. Każde sprawdzone pod kątem iCal, API, RSS, JSON-LD albo samego HTML. Projekt łączy je w jeden kalendarz iCal bez duplikatów, z linkiem do każdego źródła.

Jak to działa

Pobieranie
Python, codziennie o 12:00 przez GitHub Actions. Lokalnie: docker compose up.
Bez AI
iCal, WordPress The Events Calendar (/wp-json/tribe/…), Modern Events Calendar (RSS z mec:startDate), schema.org JSON-LD, JSON osadzony w stronie.
Z AI
Strony HTML, RSS z ogłoszeniami i roczne kalendarze PDF → Gemini flash-lite. Twardy limit 60 zapytań dziennie; strony czytane ponownie tylko po zmianie i nie częściej niż co 20–72 h, artykuły bez daty i „śmieci” odpadają przed AI.
Lokalizacja
Współrzędne ze źródła albo OpenStreetMap Nominatim (cache). Wszystko dalej niż 50 km od Rynku odpada.
Duplikaty
Ten sam dzień + podobny tytuł + start ±60 min + ta sama miejscowość = jedno wydarzenie. Główne źródło wg priorytetu (organizator > lokal > miasto > bilety > media), reszta w opisie jako „Źródła”. Wystawy dzień po dniu sklejane w jedno wydarzenie.
Facebook
Lista wydarzeń strony wymaga logowania, więc działa tylko pojedynczy publiczny link wydarzenia. Linki fb.com/events znalezione w innych źródłach są pobierane automatycznie.
Hosting
GitHub Pages, 0 zł. Kalendarze: wszystkie.ics, tarnow.ics, okolice.ics, dlugie.ics (wystawy), kategoria/*.ics.
